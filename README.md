# Pandia

Small, lightweight World of Warcraft: Forever addons.

| Addon | What it does |
|-------|----------------|
| **Pandia Nameplates** | Class-colored nameplate ToT names; Rogue/Druid Blizzard combo pips (combat only) |
| **Pandia Quest Links** | Localized / customizable quest status after chat quest links |

## Install

Copy `PandiaNameplates` and/or `PandiaQuestLinks` into:

`World of Warcraft\_forever_\Interface\AddOns\`

Enable them at character select. Forever only (`## Interface: 16001`, `AllowLoadGameType: forever`).

## Options

Esc → **Options** → **AddOns** → Pandia Nameplates / Pandia Quest Links.
