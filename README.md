# Pandia

Small, lightweight World of Warcraft: Forever addons.

| Addon | What it does |
|-------|----------------|
| **Pandia Nameplates** | Class-colored nameplate ToT names; Rogue/Druid Blizzard combo pips (combat only). `/pnplates` |
| **Pandia Quest Links** | Localized / customizable quest status after chat quest links. `/pql` |

## Install

Copy `PandiaNameplates` and/or `PandiaQuestLinks` into:

`World of Warcraft\_forever_\Interface\AddOns\`

Enable them at character select. Interface version: **16001** (Forever).

## Options

Esc → **Options** → **AddOns** → Pandia Nameplates / Pandia Quest Links.

| Addon | Slash (opens the same panel; blocked in combat) |
|-------|-------|
| Pandia Nameplates | `/pnplates` or `/pandianp` |
| Pandia Quest Links | `/pql` or `/pandiaql` |
